# 🥗 FreshLog — Smart Food Expiry & Inventory Tracker :-

**FreshLog** is a responsive, zero-typing web application designed to help households track kitchen inventory, reduce food waste, and monitor expiration timelines effortlessly. Built using modern web standards, it integrates voice recognition and OCR bill scanning so users can log items without manual typing.

## ✨ Key Features :-

- 🎤 **Voice-Powered Entry:** Add food items dynamically using natural spoken language via the browser-native **Web Speech API**.
- 📄 **Smart Grocery Bill Scanner:** Upload images of shopping receipts to extract item text automatically using **Tesseract.js (OCR)**.
- 🔍 **Verification & Review Workflow:** A human-in-the-loop verification modal allowing users to edit, check, or uncheck extracted OCR items before saving.
- ⏳ **Custom Expiry Engine:** Dynamic shelf-life calculations tailored to storage environments (**Room Temperature**, **Fridge**, **Freezer**).
- 💡 **Instant Actions:** One-click shortcuts for quick YouTube recipe ideas and Google storage tips based on items nearing expiry.
- 📱 **Mobile-First & Responsive UI:** Clean interface styled with **Tailwind CSS** for seamless operation across desktop and mobile devices.

## 🛠️ Tech Stack & Dependencies :-

- **Frontend:** HTML5, Modern JavaScript (ES6 Modules), Tailwind CSS
- **APIs & Libraries:** 
  - [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) — Browser Speech Recognition
  - [Tesseract.js](https://tesseract.projectnaptha.com/) — Client-side Optical Character Recognition (OCR)
- **Deployment:** Render (Static Site with automatic HTTPS/SSL)
